# Mini-CRM для малого бизнеса 📋

Веб-приложение для управления базой клиентов и записями на услуги. Разработано для небольших бизнесов (салоны красоты, автосервисы, репетиторы), которым нужен простой и понятный инструмент без перегруженного функционала.

## ✨ Основной функционал

- **Добавление клиентов:** запись на услугу с указанием имени, телефона и даты/времени.
- **Маска ввода:** автоматическое форматирование номера телефона в формат `+7 (999) 123-45-67` при вводе.
- **Управление статусами:** переключение статуса клиента по клику на бейдж (Новый → В работе → Оплачен).
- **Подсчет выручки:** автоматический расчет общей суммы по клиентам со статусом «Оплачен».
- **Живой поиск:** моментальная фильтрация списка по имени или номеру телефона.
- **Удаление записей:** удаление клиента из базы.
- **Экспорт данных:** выгрузка всей базы клиентов в файл формата CSV (Excel).
- **Сохранение данных:** все данные сохраняются в LocalStorage браузера и не пропадают при перезагрузке страницы.

## 🛠 Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — кастомный дизайн, Flexbox, CSS-переменные, адаптивная верстка.
- **JavaScript (Vanilla)** — без сторонних библиотек и фреймворков.
  - Работа с DOM (динамическое создание элементов).
  - Делегирование событий (Event Delegation).
  - Работа с массивами (`filter`, `findIndex`, `splice`, `forEach`, `reduce`).
  - Регулярные выражения (для маски телефона).
  - Работа с датами (`Date`, `padStart`).
  - `LocalStorage` (сериализация JSON).
  - Генерация и скачивание файлов (`Blob`, `URL.createObjectURL`).

## 🎨 Дизайн

Проект имеет минималистичный, но эстетичный дизайн. Используется палитра из двух благородных цветов:
- `Butter` (#ffec8e) — акцентный сливочный цвет.
- `Plum` (#631d3f) — глубокий сливовый цвет.

Для типографики выбран классический шрифт с засечками `Georgia`, который придает интерфейсу дорогой и профессиональный вид.

## 🚀 Как запустить

Проекту не требуется установка зависимостей или сборщиков.

1. Склонируйте репозиторий или скачайте архив с файлами.
2. Откройте файл `index.html` в любом современном браузере.

Или запустите локальный сервер (если используете VS Code + Live Server).
